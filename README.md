# Shared Wishlist App

An "Shared Wishlist App" where multiple users can create, manage, and interact with
wishlists in real-time — imagine users in a group planning a shopping spree together.

## Install and Run The application

Clone the repository:
```
git clone https://github.com/AdityaNik/wishlist-app.git
cd wishlist-app
```

To install all packages and start backend, run the following command:

```
cd backend
```

```
npm install
```

```
node src/index.js
```

## Install and Run React Frontend

To install all the packages and start frontend, run the following command:

```
cd frontend
```

```
npm install
```

```
npm run dev
```

## Deployment

services used to deploy frontend and backend

- Frontend: [Vercel](https://vercel.com/)
- Backend: [Render](https://render.com/)
- Database: [MongoDB Compass](https://www.mongodb.com/)
